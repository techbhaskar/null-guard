# Security policy

Report vulnerabilities in NullGuard privately to [ARINITS](mailto:admin@arinits.com?subject=NullGuard%20security%20report). Include the affected NullGuard version, the affected component, and the impact. Use a minimal example with sensitive data removed. Keep unpublished vulnerability details out of public issues and pull requests.

Check the [GitHub security advisories](https://github.com/techbhaskar/null-guard/security/advisories) for published disclosures and available fixes.

For installation help, compatibility questions, and ordinary bug reports, use the [GitHub issue tracker](https://github.com/techbhaskar/null-guard/issues). Include the NullGuard version, JDK version, and integration. Share sanitized excerpts if needed. The public issue tracker is a best-effort support channel without a response-time commitment.

For CI deployments, see the [data handling and offline configuration guide](docs/cve-analysis.md#ci-data-handling).
