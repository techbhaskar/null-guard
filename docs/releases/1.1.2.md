# NullGuard 1.1.2

This is a GitHub source/tag release (`v1.1.2`). Maven Central publication is pending;
`1.1.1` remains the latest confirmed Central publication. No Central upload is part
of this release preparation.

## Changes

- More conservative call resolution, canonical method matching, and constructor contracts.
- Explicit, implicit, and common Lombok constructors modeled without running annotation processors.
- Ordered instance/static initialization and constructor delegation.
- Bounded local allocation, alias, and mutation tracking with `NG006` null-field findings,
  including manually constructed framework-managed components.
- Source-proven validation helpers and constructor parameter checks; no safety inferred
  solely from a helper's name.
- Fixed annotation-import leakage between unrelated classes.
- Analysis-completeness metadata and dashboard details for unresolved calls, generated
  executables, external dependency bodies, and construction/lifecycle limitations.

See [analysis behavior, limitations, and verification](../analysis-completeness.md).
Reflection, dynamic proxies, and complex heap/runtime behavior remain outside these
static guarantees. This is not runtime memory analysis or a whole-program safety proof.

## Build and use locally

Requires JDK 17 or 21 and Maven. From the repository root:

```sh
mvn --batch-mode clean install
java -jar nullguard-cli/target/nullguard-cli-1.1.2-jar-with-dependencies.jar path/to/service/src/main/java --output=target/nullguard
```

Open `target/nullguard/nullguard-dashboard-latest.html` after the CLI run.
`mvn verify` in this repository builds/tests NullGuard; it does not by itself analyze
another microservice or generate that service's dashboard.

After `mvn install`, another Maven project can use the locally installed plugin:

```sh
mvn com.arinits.nullguard:nullguard-maven-plugin:1.1.2:analyze -Dnullguard.failBuild=false
```

Do not expect version `1.1.2` to resolve from Maven Central until separately published.

## Verification

The versioned `1.1.2` reactor passed `mvn --batch-mode "-Djacoco.append=false" verify`:
142 tests passed, one opt-in benchmark was skipped, and aggregate coverage was
87.1% instructions / 69.9% branches (80% / 60% gates passed). The packaged `1.1.2`
CLI generated the sample microservice dashboard, OpenAPI, and SARIF reports.
The four independent OpenAPI regression fixtures and packaged CLI OpenAPI/SARIF
outputs passed schema validation. The Gradle integration test task also passed
(`gradlew.bat test --no-daemon`); its published-CLI fixture exercises an existing
published analyzer, not a claim that `1.1.2` is already available from Central.
Twelve dedicated constructor/lifecycle regressions and earlier packaged CLI /
schema checks are also documented in the analysis notes.
The 50,000-method benchmark was not rerun for this release.
