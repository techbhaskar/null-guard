## Changes

- Locally bundled Swagger UI in the unified dashboard and standalone Swagger page.
- Explicit server, title/version, bearer/basic/API-key and opt-in live-request configuration across Maven, Gradle and CLI.
- Full literal path arrays and multiple HTTP verb export, stable operation IDs and explicit operation-conflict failures.
- Collision-safe DTO schema names and correct nullable reference semantics for OpenAPI 3.0.
- Removal of risk-inferred HTTP error contracts; typed maps, nested response containers and bodyless response handling.
- Independent OpenAPI document and nullable-instance validation plus Windows-compatible Gradle integration checks.

Live API execution remains disabled by default. OAuth2 and richer framework/serialization extraction remain limitations documented in the README. No production application calls are made during static analysis.

## Installation

```sh
mvn com.arinits.nullguard:nullguard-maven-plugin:1.1.1:analyze
```

Open `target/nullguard/nullguard-dashboard-latest.html`. Keep the neighboring
`swagger-ui/` directory when sharing the report.

Gradle plugin: `com.arinits.nullguard`, version `1.1.1`; configure Maven Central
in `pluginManagement.repositories` as described in the [Gradle guide](../../nullguard-gradle-plugin/README.md).

No 1.1.1 GitHub release or GitHub Packages mirror publication is claimed here.
