# NullGuard 2.0.1

Release date: 2026-11-09. Published on Maven Central and GitHub Packages.

[Download the signed release](https://github.com/techbhaskar/null-guard/releases/tag/v2.0.1).
All 13 registry components and 45 original artifacts were downloaded and byte-verified.

## Changes

- Gradle analyzes selected original Java sources in place, including multiple and
  generated source roots. It writes a small source-path manifest instead of copying
  application sources. Exclusions and configuration-cache reuse are preserved;
  SARIF links resolve to original files.
- The Java multi-language adapter also analyzes original selected files and keeps
  parent and nested module ownership separate. Empty selections fail explicitly.
- The Gradle plugin runs the standalone CLI with transitive resolution disabled,
  preventing application BOMs from downgrading SpotBugs/BCEL runtime dependencies.
- The dashboard adds separate JaCoCo Coverage and Code Quality & Fixes tabs.
  Coverage requires an actual JaCoCo XML report; quality remediation is guidance,
  not automatic source edits or SonarQube scan results.
- Current OSV advisory lookup is enabled by default, with pagination, hydrated
  advisory records, source dates, aliases, reported fixes and explicit failure
  status. `--cve-offline` disables network lookup. Online lookup sends dependency
  coordinates to OSV, not application source.
- Additional analysis tests cover lifecycle behavior, contract checks, hotspot
  scoring and orchestration.

## Compatibility

Use Java 21 or later. Upgrade both Maven/Gradle plugin and CLI to 2.0.1.
No `-I` development helper is required with the released Gradle plugin.

Native language-pack binaries, signatures and protocol remain at 2.0.0; the
2.0.1 JVM distribution remains compatible with those unchanged signed packs.
Python, JavaScript/TypeScript, C#, Go and Rust packs remain experimental and
report-only. This patch makes no new general accuracy or runtime-safety claim.

Version 2.0.0 artifacts are unchanged.
