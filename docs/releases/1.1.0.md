# NullGuard 1.1.0

Status: release preparation; not yet uploaded.

## Changes

- Branch-sensitive ternary/short-circuit analysis, pattern variables and catch parameters.
- Scoped Spring injection/MVC/AspectJ and Lombok/logger-factory contracts; optional values remain conservative.
- Java 17 syntax in the source parser, type solver and CFG expression parser.
- Unresolved calls remain external instead of connecting unrelated same-name methods.
- Unified offline HTML dashboard for Maven, Gradle and the CLI, with streaming report generation.
- OpenAPI 3.0 export and DTO schemas, including class-level paths and common request metadata.
- Static-analysis and architecture findings (NG201–NG302).
- Preview dependency CVE reporting (NG401–NG403): limited built-in catalog, offline imports and opt-in OSV queries. Reachability is an estimate, not proof of exploitability or safety.

The private-application validation is documented in
[null-analysis corrections](../evaluation/null-analysis-corrections.md). Continue
report-only adoption until findings are independently reviewed.

## Installation after publication

```sh
mvn com.arinits.nullguard:nullguard-maven-plugin:1.1.0:analyze
```

Gradle plugin: `com.arinits.nullguard`, version `1.1.0`; configure Maven Central
in `pluginManagement.repositories` as described in the [Gradle guide](../../nullguard-gradle-plugin/README.md).
